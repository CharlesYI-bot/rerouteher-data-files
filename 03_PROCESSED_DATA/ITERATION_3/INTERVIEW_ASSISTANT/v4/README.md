# Version 4 contents

`ReRouteHer_MASCO631_Interview_Coach_Dataset_v4.xlsx` is the review-ready workbook. The `csv` directory contains matching machine-readable exports.

Question delivery should use `Session Blueprints` to select from `General Questions` and `Role Questions`. AI feedback should use `AI Evaluation Rubric`; there are no stored model answers.

The 12 role-specific categories are introduction, motivation, three behavioural prompts, three technical prompts, two situational prompts, career growth, and `questions_for_interviewer`. General and Mixed sessions also guarantee broad behavioural coverage such as conflict, teamwork, problem solving, reflection, prioritisation, communication, integrity, and adaptability.

Every source-derived open question includes licence and attribution metadata. Review technical currentness and role relevance before surfacing it to users.
